EventReduce Browser Demo

This is the browser demo where the EventReduce algorithm is used in different browser databases so you can test out the performance gains of different queries.

100 events (no EventReduce)

This will run 100 random events and after each event it will use EventReduce to calculate the new results



Limit buffer:

Runs 100 random events on the current query and updates its result in three ways: a full query after each event, EventReduce, and EventReduce with a limit buffer that keeps rows before and after the result window in memory, so rows that move into the window can be taken from memory instead of a query. The query must have a limit or a skip.
